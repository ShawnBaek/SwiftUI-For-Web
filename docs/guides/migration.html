Migrating from 3.0 to 3.1

Upgrading from 3.0.0-alpha.1, 3.0.0-alpha.2 or an earlier 3.x checkout. These are the breaking entries of the CHANGELOG, with what to change.

The *View classes are gone

Every built-in view is a descriptor built by its factory function: the form controls in alpha.2, and in 3.1 the containers, navigation, shapes, grids, lazy stacks, scenes, gradients and Chart. Factory signatures, DOM, styles, ARIA and keyboard behaviour are unchanged. Each modifier returns a new descriptor instead of mutating the view.

BeforeAfter
new ToggleView('Wi-Fi', isOn.binding)Toggle('Wi-Fi', isOn.binding)
view._render(), view.getElement()Mount it: App(view).mount(host) (then host.firstElementChild if you need the element), or renderToString(view) from swiftui-for-web/server on a server or in tests
x instanceof ListViewx.type === 'List'
view._label and other internalsview.props (read-only), or better, the bindings you passed
ScrollView(…).scrollTo(…), scrollToTop, scrollToBottom.modifier((element) => …) that keeps the element and scrolls it
TabView._pageIndicatorVisibility.tabViewStyle(TabViewStyle.page, { indexDisplayMode: 'never' })
TupleViewViewBuilder.buildBlock returns a Group
new ConditionalContent(…)ConditionalContent(…) (a function), or Show

Removed classes: ToggleView, SliderView, StepperView, TextFieldView, SecureFieldView, PickerView, DatePickerView, ColorPickerView, ListView, SectionView, FormView, ScrollViewView, GroupView, DisclosureGroupView, TabViewView, MenuView, LabelView, ImageView, ShapeView and the shape classes, GridView, GridRowView, the lazy grid and stack classes, GeometryReaderView, WindowGroupView, SettingsView, DocumentGroupView and TupleView, along with src/Core/LegacyControl.js (defineControl).

import { App, VStack, Toggle, Text, State } from 'swiftui-for-web';

const isOn = new State(true);

// Before: new ToggleView('Wi-Fi', isOn.binding).toggleStyle('checkbox')._render()
const toggle = Toggle('Wi-Fi', isOn.binding).toggleStyle('checkbox');
console.log(toggle.type);          // 'Toggle', instead of instanceof ToggleView

// Modifiers return new descriptors; keep the result.
const padded = toggle.padding(8);
console.log(toggle === padded);    // false

App(() => VStack(padded, Text(() => (isOn.value ? 'On' : 'Off')))).mount('#root');

View stays only as a deprecated adapter for your own class views (class MyView extends View { body() { … } } still renders, with the same modifiers); development builds warn once when a class extends it. Prefer functions that return descriptors.

extend* helpers removed

RemovedInstead
extendViewWithAnimationNothing: .animation, .transition and .matchedGeometryEffect are on every view.
extendViewWithGesturesNothing: .gesture, .onLongPressGesture, .onDrag and the composition modifiers are on every view.
extendNavigationStackWithPathNavigationStack(root, { path }) with .navigationDestination(dataType, build). (The helper never worked.)
import { App, NavigationStack, NavigationPath, VStack, Text, Button } from 'swiftui-for-web';

class Item {
  constructor(id) { this.id = id; }
}

const path = new NavigationPath();

const Home = () =>
  VStack({ spacing: 12 },
    Text('Home'),
    Button('Open item 42', () => path.append(new Item(42)))
  ).padding(24);

// Like SwiftUI's .navigationDestination(for: Item.self) { item in … }
App(() =>
  NavigationStack(Home(), { path })
    .navigationDestination(Item, (item) =>
      VStack({ spacing: 12 },
        Text(`Item ${item.id}`),
        Button('Back', () => path.removeLast())
      ).padding(24))
).mount('#root');

Performance internals moved to swiftui-for-web/performance

The scheduler (scheduleWork, schedulePostFlush, batchUpdates, endBatch, enqueueDOMWrite, getSchedulerStats, resetSchedulerStats, the SyncLane … IdleLane constants), the element pool (acquireElement, releaseElement, releaseTree, getPoolStats, clearPools), event delegation (delegateEvent, undelegateEvent, initDelegation, teardownDelegation) and promoteToGPULayer/demoteFromGPULayer left the main entry and ./core. batch and flushSync stay.

// Before: import { scheduleWork, SyncLane, acquireElement } from 'swiftui-for-web';
import { scheduleWork, SyncLane, getSchedulerStats } from 'swiftui-for-web/performance';
import { batch } from 'swiftui-for-web';

scheduleWork(() => console.log('ran in the sync lane'), SyncLane);
batch(() => {});
setTimeout(() => console.log('scheduler stats:', getSchedulerStats()), 50);

Chart and the marks are descriptors

Chart, BarMark, LineMark, AreaMark, PointMark, RuleMark, RectangleMark and SectorMark are plain functions that build descriptors. The chart and mark methods (.chartXAxis, .foregroundStyle, .interpolationMethod, …) return new descriptors, and the SVG output is the same, attribute for attribute.

BeforeAfter
mark instanceof BarMarkmark.type === 'BarMark'
mark.xmark.props.x
chart._render()Mount it with App(chart).mount(host), or renderToString(chart) from swiftui-for-web/server
Mark base classRemoved (an interface in the type declarations)
getX, getY, markType, clone, render, getPointData, getAngleValue, LineMark.generatePath, AreaMark.generateAreaPathRemoved

Also new: Chart([marks]) draws an array of marks (it drew an empty plot before), a chart redraws when a State its data or builder reads changes, and a mark used on its own renders as a one-mark chart. createChart, createBarMark, … remain as aliases.

import { App, Chart, BarMark, RuleMark, State, Button, VStack, value, Color } from 'swiftui-for-web';

const data = new State([
  { day: 'Mon', steps: 6200 }, { day: 'Tue', steps: 8100 }, { day: 'Wed', steps: 7400 },
]);

const chart = Chart(() => [
  ...data.value.map((d) => BarMark({ x: value('Day', d.day), y: value('Steps', d.steps) })),
  RuleMark({ y: value('Goal', 7000) }).foregroundStyle(Color.red),
]).frame({ width: 360, height: 200 });

console.log(chart.type, chart.props !== undefined);

App(() =>
  VStack({ spacing: 12 },
    chart,
    Button('Add Thursday', () => { data.value = [...data.value, { day: 'Thu', steps: 9000 }]; })
  ).padding(16)
).mount('#root');

Entry points

  • swiftui-for-web/src/* is no longer importable. Use the main entry, ./core (everything but Charts), ./charts, ./server, ./islands or ./performance. Stylesheets are at swiftui-for-web/styles/*. Anything else is under swiftui-for-web/internal/*, with no stability promise.
  • Importing a Charts name from ./core is now a type error instead of a load-time failure.

Behaviour changes to check

  • Group is transparent to the enclosing stack: a Spacer in a Group in an HStack is horizontal.
  • Capsule always uses border-radius: 9999px.
  • Built-in views are tagged with data-view (data-view="Image", data-view="Chart", …): update selectors and snapshots that match on markup.
  • TabView, Picker, Stepper, DatePicker, ColorPicker, DisclosureGroup and a selectable List follow binding writes made elsewhere.
  • ForEach given a State or a function is reactive; For is deprecated.

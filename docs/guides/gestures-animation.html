Gestures and animation

Every view has the gesture and animation modifiers, backed by native browser APIs: pointer and touch events, the Web Animations API, CSS transitions and the View Transitions API.

Gestures

ModifierUse
.onTapGesture(action)A tap. Several tap handlers on a view compose in modifier order, and Button(…).onTapGesture(f) runs both.
.onLongPressGesture(action, { minimumDuration })A long press.
.onDrag(onChanged, onEnded)A drag; each callback receives { translation, location, startLocation }.
.gesture(g, { including })Any recognizer: TapGesture(count), LongPressGesture({ minimumDuration }), DragGesture({ minimumDistance }), MagnificationGesture(), RotationGesture().
.simultaneousGesture(g)Recognizes together with the view’s own gestures.
.highPriorityGesture(g)Wins over gestures of the same kind on the view and inside it.

Recognizers chain .onChanged(value => …) and .onEnded(value => …). Each element keeps its own gesture state, so one recognizer can sit on every row of a list, and listeners are removed when the element is released or its owner is disposed.

import {
  App, VStack, HStack, Text, State, TapGesture, LongPressGesture, DragGesture, Color
} from 'swiftui-for-web';

const parentTaps = new State(0);
const childTaps = new State(0);
const presses = new State(0);
const drag = new State('Drag the label');

App(() =>
  VStack({ spacing: 16 },
    // High priority: a tap on the child counts for the parent only.
    HStack({ spacing: 12 },
      Text('Child').padding(10).background(Color.secondarySystemBackground)
        .gesture(TapGesture().onEnded(() => { childTaps.value += 1; })),
      Text(() => `parent ${parentTaps.value} · child ${childTaps.value}`)
    )
      .padding(10)
      .border(Color.gray)
      .highPriorityGesture(TapGesture().onEnded(() => { parentTaps.value += 1; })),

    // Simultaneous: the long press and the tap both recognize.
    Text(() => `Long presses: ${presses.value}`)
      .padding(10)
      .background(Color.orange)
      .foregroundColor(Color.white)
      .onTapGesture(() => console.log('tap'))
      .simultaneousGesture(LongPressGesture({ minimumDuration: 0.4 }).onEnded(() => { presses.value += 1; })),

    Text(drag)
      .padding(10)
      .border(Color.blue)
      .gesture(DragGesture()
        .onChanged((value) => { drag.value = `Δ ${value.translation.width}, ${value.translation.height}`; })
        .onEnded(() => { drag.value = 'Dropped'; }))
  ).padding(24)
).mount('#root');

GestureMask chooses what .gesture(g, { including }) enables: GestureMask.all (the default), gesture (disables the gestures inside the view), subviews (disables g) and none (disables both).

Not yet like SwiftUI: a parent’s and a child’s plain .gesture of the same kind both fire (SwiftUI lets the child win; use .highPriorityGesture or GestureMask to choose). Gestures of different kinds don’t arbitrate, Button actions are not gestures, a high-priority gesture takes the interaction even when it fails, and SequenceGesture, ExclusiveGesture and @GestureState are missing. The list is kept in docs/parity-audit.md.

withAnimation and .animation

withAnimation(animation, body) runs body and animates the changes it makes; it returns a promise that resolves when the animation ends. .animation(animation, value) animates a view’s own style changes with a CSS transition; .animation(null) turns it off. Animations: Animation.default, linear(d), easeIn(d), easeOut(d), easeInOut(d), spring(options), smooth, snappy, bouncy.

import { App, VStack, Text, Button, State, Animation, withAnimation, Color } from 'swiftui-for-web';

const faded = new State(false);
const opacity = new State(1);

App(() =>
  VStack({ spacing: 16 },
    Text('Fades with .animation')
      .padding(16)
      .background(Color.blue)
      .foregroundColor(Color.white)
      .opacity(opacity)                       // a State: updates on its own
      .animation(Animation.easeInOut(0.5)),
    Button('Toggle', () => {
      withAnimation(Animation.spring(), () => {
        faded.value = !faded.value;
        opacity.value = faded.value ? 0.25 : 1;
      });
    })
  ).padding(24)
).mount('#root');

Transitions: insertion and removal

.transition(t) says how a view enters and leaves. Insertion animates when the view is inserted inside withAnimation. Removal animates when Show, a reactive ForEach or a navigation pop removes the view, inside withAnimation or when the transition carries its own animation (AnyTransition.opacity.animation(Animation.easeOut(0.2))). The leaving element stays in the document while it animates, without pointer events and with aria-hidden; its effects are disposed at once.

Transitions: AnyTransition.opacity, scale(s), slide, move(edge), push(edge), identity, asymmetric(insertion, removal) and t.combined(other). With prefers-reduced-motion, no transition, or no animation, removal is immediate.

import {
  App, VStack, Text, Button, ForEach, State, AnyTransition, Animation, withAnimation, Color
} from 'swiftui-for-web';

const items = new State([1, 2, 3]);
let next = 4;

const Row = (item) =>
  Text(`Item ${item}`)
    .padding(10)
    .frame({ width: 200 })
    .background(Color.secondarySystemBackground)
    .cornerRadius(8)
    .transition(AnyTransition.asymmetric(AnyTransition.move('leading'), AnyTransition.opacity));

App(() =>
  VStack({ spacing: 8 },
    Button('Add', () => {
      withAnimation(Animation.easeOut(0.3), () => { items.value = [...items.value, next++]; });
    }),
    Button('Remove first', () => {
      withAnimation(Animation.easeIn(0.3), () => { items.value = items.value.slice(1); });
    }),
    ForEach(items, { id: (item) => item }, Row)
  ).padding(24)
).mount('#root');

matchedGeometryEffect

Views with the same id in a Namespace() morph into each other when one replaces the other inside withAnimation, through a View Transition (where the browser supports it).

import {
  App, VStack, HStack, Text, Show, State, Namespace, withAnimation, Animation, Color, Font
} from 'swiftui-for-web';

const expanded = new State(false);
const ns = Namespace();
const toggle = () => withAnimation(Animation.spring(), () => { expanded.value = !expanded.value; });

App(() =>
  VStack({ spacing: 12 },
    Text('Tap the card').foregroundColor(Color.secondary),
    Show(() => expanded.value,
      VStack({ alignment: 'leading', spacing: 8 },
        Text('Big card').font(Font.title),
        Text('Tap to collapse')
      )
        .padding(24)
        .frame({ width: 280, height: 180, alignment: 'topLeading' })
        .background(Color.indigo)
        .foregroundColor(Color.white)
        .cornerRadius(20)
        .matchedGeometryEffect('card', ns)
        .onTapGesture(toggle),
      HStack(Text('Small card'))
        .padding(12)
        .background(Color.indigo)
        .foregroundColor(Color.white)
        .cornerRadius(12)
        .matchedGeometryEffect('card', ns)
        .onTapGesture(toggle)
    )
  ).padding(24)
).mount('#root');
